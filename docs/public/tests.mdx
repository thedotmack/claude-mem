# Validation

## Observer recovery after a provider deadline

The regression test in
[`tests/worker/http/routes/session-routes-deadline-resume.test.ts`](https://github.com/thedotmack/claude-mem/blob/main/tests/worker/http/routes/session-routes-deadline-resume.test.ts)
starts a real session buffer through the OpenRouter provider path, makes an
observer request exceed its per-attempt deadline, and verifies that the same
queued observation is processed by a later generation without another hook.
It also checks that a removed session is not restarted, repeated
transport pauses back off, and simultaneous paused sessions are admitted one
at a time. The focused `openai-compatible-failed-turn.test.ts` check verifies
that failed init, observation, and summary requests leave no duplicate user
turn in the next attempt's conversation history.

Run the focused check from the repository root:

```bash
bun test tests/worker/http/routes/session-routes-deadline-resume.test.ts tests/worker/openai-compatible-failed-turn.test.ts
```

The adjacent `overflow-recycle-resume.test.ts` and
`generator-exit-preserves-work.test.ts` cases cover the distinct overflow,
quota, authentication, and transport preservation paths.
