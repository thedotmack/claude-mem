## Primary goal

**A standing CCS Align seat can talk to the local Claude-Mem worker, pull observations through the existing search → timeline → get_observations ladder, and land them in a seat-owned middle cache using grab → append → replace (or append-only if the original cache is not writable) — without shipping a context compiler, without deleting history, and without writing Grok `profile.md`.**

Everything below is measured against that sentence. A task that does not move the house from “diary and Grok log are two islands” toward “one auditable middle cache the Align seat can rebuild” does not belong in this plan.

## The problem in one paragraph

Claude-Mem already has a trustworthy episodic feed (`search` → `timeline` → `get_observations`) and, as of #3931, a *push* of needle facts into LFG/Orifice monthly logs. What the house does **not** have is a Cascading Context Sheet *runtime*: a place between the diary and the compiled prompt where observations can be grabbed, appended, replaced, and later excluded — plus a periodic pass over house → project → seat rules so leaf copies do not silently shadow the cascade. The full brainbeat / context-compiler is future work (paper scaffold says so out loud). CCS Align is the **interim seat**: one job, hourly, copy-from-docs, fail closed.

## Binding constraints

1. **Seat, not bird’s-eye.** CCS Align is a Worker Watch–shaped standing seat (hourly board). It does not prioritize the house, hire, or redesign memory. Prioritizer owns that.
2. **Copy from existing APIs.** Progressive disclosure and the #3931 atomic append are already in-tree. Do not invent `compileAwareness()`, `brainbeatPush()`, `excludeObservation()`, or a `.cas` parser.
3. **History is append-only.** Exclude marks filter *compiled* awareness. They do not `DELETE /api/observation/:id` and they do not rewrite SQLite rows. Graphiti-style invalidate; never A-MEM rewrite ([Memory dig findings](https://app.notion.com/p/3d3771da7f4d8139a2e8fd3a3c9ceb05)).
4. **Do not second-write LFG/Orifice logs.** #3931 already appends `- YYYY-MM-DD [awareness] …` to `agents/<id>/memory/log/YYYY-MM.md`. Q8 for a second writer was answered yes *for that pusher*. CCS Align writes a **seat-owned** middle cache unless a later PASS explicitly names another path.
5. **Never write `profile.md`, user-memory, or project memory.** Same hard rule as `GrokBotAwarenessPusher.ts` (`assertSafeAwarenessLogPath`).
6. **No top-of-prompt clock.** House rule: timestamps belong on facts, not as a header that busts prefix cache.
7. **Address Alex, never Az,** in every user-facing string this work adds.
8. **Do not edit `CHANGELOG.md`** (generated). If a later `/do` ships code, the changelog job will pick it up.
9. **No new runtime dependency.** Reuse `fs` rename, existing MCP/HTTP, existing settings loader.
